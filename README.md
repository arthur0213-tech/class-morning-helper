# 🏫 班級早修小幫手 (Classroom Morning Assistant)
### 專為國小 75 吋觸控大螢幕設計・遊戲化多班級存檔・總管理員控制台・Firebase 跨裝置即時同步

🔗 **正式版直接開啟網址**：[https://arthur0213-tech.github.io/class-morning-helper/](https://arthur0213-tech.github.io/class-morning-helper/)

---

## 🌟 核心特色

1. **🎮 遊戲化多班級獨立存檔（多使用者互不干擾）**：
   - 每個班級就像「獨立遊戲存檔」，各自擁有專屬的班級名稱、座號範圍、每日打卡紀錄、聯絡簿與管理密碼。
   - **專屬班級網址**：每個班級都有專屬網址（例如 `?class=101` 或 `?class=302`），學生或教室大螢幕點開就是該班專屬控制台，**完全不需帳號登入**，絕不互相覆蓋！
   - 支援隨時點擊頂端班級標籤切換班級，或一鍵新增全新班級存檔。

2. **⏰ 到校打卡與逾時紅標補打卡**：
   - **防重複點擊與準時金黃色標記**：準時打卡記錄到校時間（如 `07:28`），呈現亮麗金黃色。
   - **截止後依然可打卡（自動變紅）**：超過截止時間（預設 `08:05`）後按鈕不鎖死，學生依然可補打卡，打卡後自動轉為鮮明**熱情紅色漸層**並標記「遲到」，一目了然！
   - 支援個別座號免打卡（請假/公假）設定。

3. **📅 過往歷史打卡紀錄隨時調閱與更正**：
   - **首頁快捷調閱**：首頁「到校打卡」標題旁新增「📅 歷史」快捷鍵，輸入教師密碼直達歷史紀錄面板。
   - **任意日期翻閱**：支援「◀ 前一天」、「▶ 後一天」、「日期選擇器」與「回到今天」，各天出席狀況完整永久保存於雲端。
   - **出席統計與 LINE 一鍵通報**：提供應到、準時、遲到、未到、免打卡統計列，並支援「一鍵複製 LINE 出席通報」，方便直接貼上班級群組。

4. **📖 一年級聯絡簿超大方格對照（字級極致放大・後排無憂）**：
   - **100% 垂直空間釋放**：移除佔用空間的急轉彎，聯絡簿寫字格全面加高至 **88px**、欄寬 **104px**。
   - **國字大字不加粗（42px）**：國字放大至 **42px**（筆畫清晰舒展不相黏），純國字模式達 **48px**。
   - **直式注音大字排版**：注音符號與聲調等比例放大，直式居中排列絕不歪斜，純注音模式移除中間虛線。
   - **單元課次整合單格**：自動識別 `U5`、`L3`、`CH2`、`ㄓ5` 等代號，完美保持在單一格子內不截斷。
   - **民國 115 年全直式日期欄**：完整帶入民國年、月份、日期與星期，全直式注音對照。
   - **標準直式標點**：標點符號全自動轉為標準直式標點（`︵`、`︶`、`﹁`、`﹂`、`~` 等）。

5. **📝 作業補繳與個別座號管理**：
   - 支援「指定座號補繳」與「全班補繳」模式。
   - 學生補繳後點選座號立即變色並顯示綠色打勾（✓），進度條即時更新。

6. **👑 全校總管理員控制台 (Super Admin)**：
   - 輸入總管理員專屬密碼（預設 `super9999`）即可進入。
   - **全校班級使用者總覽名冊**：一覽全校所有使用班級、指導老師、學生人數、今日出席率與專屬網址。
   - **一鍵派發專屬連結**：直接複製專屬網址發給各班老師加入書籤。
   - **全校總備份與還原**：一鍵打包匯出全校所有班級歷史資料。

7. **☁️ 離線/雲端雙引擎儲存**：
   - **本機離線模式**：預設使用瀏覽器 `localStorage`，重新整理或重開機資料永久保存。
   - **Firebase 即時同步**：啟用 Google Firebase Realtime Database 後，老師手機、筆電與教室大螢幕雙向即時毫秒級同步！

## 🚀 部署上線指南

### 方式一：交由 Google Antigravity 全自動部署（最推薦）
1. 將整個專案交給 Google Antigravity。
2. Antigravity 將自動完成 GitHub 儲存庫建立、GitHub Pages 靜態網站發布與 Firebase 雲端資料庫串接與備份。

---

### 方式二：手動發布至 GitHub Pages
1. 登入 [GitHub](https://github.com/)，在儲存庫 `class-morning-helper` 中上傳 `index.html` 與相關檔案。
2. 前往儲存庫的 **Settings** ➔ 側邊欄點選 **Pages**。
3. 在 **Build and deployment** 下方的 **Branch** 選擇 `main`，資料夾保持 `/ (root)`，點擊 **Save**。
4. 正式版線上網址即刻生效：
   `https://<您的帳號>.github.io/class-morning-helper/`
   👉 **發給其他老師時，只要在網址後面加上班級代碼（例如 `?class=101`），該老師就能擁有完全獨立的專屬班級！**

## 🔑 預設密碼說明
* **個別班級教師管理密碼**：預設為 `8888`（各班老師可在後台自由修改）。
* **全校總管理員密碼**：預設為 `super9999`（於密碼驗證框輸入即可開啟全校總控制台）。
